# WXML Formatter v1.3.0 优化总结

## 优化概览

本次优化是对 WXML Formatter 的重大重构，代码量减少 80%，性能和可维护性大幅提升。

## 核心改进

### 1. 代码量优化

| 指标 | v1.2.4 | v1.3.0 | 改进 |
|------|--------|--------|------|
| 代码行数 | 1335 | ~260 | **-80%** |
| 方法数量 | 30+ | 10 | **-67%** |
| 重复代码 | 多处 | 0 | **-100%** |

### 2. 架构重构

#### 旧架构问题
- 多次迭代处理（最多 10 次）
- 大量重复方法（`finalIndentFix`、`simpleIndentCalculation`、`recalculateIndentation` 等）
- 字符串操作混乱，难以维护
- 逻辑分散，职责不清

#### 新架构优势
```
输入文本
  ↓
保护特殊语法 (protectSpecialSyntax)
  ↓
规范化自闭合标签 (normalizeSelfClosingTags)
  ↓
Token 化解析 (tokenize)
  ↓
构建文档 (buildDocument)
  ↓
恢复特殊语法 (restoreSpecialSyntax)
  ↓
最终清理 (finalCleanup)
  ↓
输出格式化文本
```

**特点：**
- 单向数据流，清晰易懂
- 一次遍历完成，无重复处理
- 结构化 Token 接口，类型安全
- 职责分离，易于测试和维护

### 3. 关键技术改进

#### Token 化解析
```typescript
interface Token {
  type: 'open' | 'close' | 'selfClose' | 'text' | 'comment';
  content: string;
  tagName?: string;
  attributes?: ParsedAttribute[];
}
```

**优势：**
- 结构化数据，易于处理
- 类型安全，减少错误
- 属性预解析，提升效率

#### 属性解析增强
```typescript
// 支持占位符格式
const regex = /([\w-:]+|__WXML_\w+_\d+__)=("[^"]*"|'[^']*')/g;
```

**解决问题：**
- 正确识别 `bind:tap` 等 WXML 指令
- 支持占位符格式的属性（`__WXML_DIR_0__`）
- 准确计算属性数量，触发换行

#### 处理优先级优化
```typescript
// 优先级顺序（从高到低）
1. 多属性标签（>3 个属性）→ 换行显示
2. 内联标签（text、icon）→ 保持同行
3. 短文本标签（≤50 字符）→ 保持同行
4. 普通标签 → 正常处理
```

**效果：**
- `<button class="..." bind:tap="..." ...>` → 正确换行
- `<text>内容</text>` → 保持同行
- `<view>页面1</view>` → 保持同行

## 修复的问题

### 1. 多属性标签未换行
**问题：** 6 个属性的 button 标签未换行
```xml
<!-- 错误 -->
<button class="btn" style="color: red;" bind:tap="onTap" data-id="{{item.id}}" data-type="{{item.type}}" disabled="{{loading}}">提交</button>
```

**原因：**
- 属性解析正则不支持占位符格式
- 处理优先级错误，短文本检查在多属性之前

**修复：**
```xml
<!-- 正确 -->
<button
  class="btn"
  style="color: red;"
  bind:tap="onTap"
  data-id="{{item.id}}"
  data-type="{{item.type}}"
  disabled="{{loading}}">
  提交
</button>
```

### 2. 短文本标签格式
**问题：** `<view>页面1</view>` 被拆分成多行

**修复：** 50 字符以内的文本保持同行
```xml
<!-- 正确 -->
<swiper-item>
  <view>页面1</view>
</swiper-item>
```
